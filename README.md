🔐 AkunKu - CapCut Account Manager

AkunKu adalah aplikasi manajer akun berbasis web tunggal (single-page application) yang dirancang khusus untuk mengelola puluhan hingga ratusan akun dengan aman. Dibuat dengan antarmuka Neon Glassmorphism yang modern, futuristik, dan sangat responsif.

✨ Fitur Utama

🎨 Modern UI/UX: Desain antarmuka Glassmorphism dengan efek neon yang memanjakan mata.

⚡ Real-time Database: Sinkronisasi data seketika menggunakan Firebase Realtime Database.

📂 Kategori Folder: Manajemen akun cerdas dengan pengelompokan (Akun Baru, Budy, Partner).

👁️ Keamanan Visual: Fitur sembunyikan/tampilkan password (toggle visibility).

📋 Copy to Clipboard: Salin username dan password hanya dengan satu klik (sekarang mendukung salin email!).

💾 Export & Backup: Dukungan penuh untuk mengekspor data akun ke format JSON, CSV (Excel), dan PDF.

🔄 Restore Data: Kembalikan (import) data akun dengan mudah dari file backup JSON Anda.

📱 Responsif: Tampilan yang menyesuaikan dengan sempurna di perangkat Desktop maupun Mobile (Bottom Navigation).

🛠️ Teknologi yang Digunakan

HTML5, CSS3, JavaScript (ES6 Modules)

Tailwind CSS (via CDN) untuk styling yang cepat dan konsisten.

Phosphor Icons untuk ikonografi yang minimalis.

Firebase v11 (Auth & Realtime Database) untuk Backend (Serverless).

jsPDF & AutoTable untuk fitur pembuatan laporan PDF.

🚀 Cara Penggunaan

Karena aplikasi ini sepenuhnya berbasis client-side (Serverless), Anda tidak perlu melakukan instalasi server yang rumit:

Unduh atau clone repository ini.

Cukup buka file index.html di browser pilihan Anda (Chrome, Safari, Edge, Firefox).

Aplikasi akan otomatis melakukan login anonim (Firebase Anonymous Auth) dan membuat ruang penyimpanan khusus untuk device Anda.
